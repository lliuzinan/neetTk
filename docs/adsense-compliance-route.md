# MedQGo：低价值内容整改与持续建设路线

2026-10-30 更新，北京时间。此文件为当前优先级依据；优先于旧路线图中的日期顺序。它是我们的执行方案，不是 Google 的通过保证。

## 结论与定位

定位收敛为：面向英语阅读的 NEET-UG Biology 学习者，帮助读者用证据解释遗传问题的独立学习网站。核心贡献是解释推理过程、显式假设、反例与结论边界，以及可保存的学习成果。先完成遗传模块，再决定是否扩展第二个模块；不继续按文章数量生产。

AdSense 的“低价值内容”通知确认了一个站点层面的审核问题，但没有列出具体问题 URL，也没有证明唯一原因是流量、AI、站龄、视觉设计或文章字数。不能把搜索排名、收录和 AdSense 广告资格视为同一次审核。

## 持久内容结构

| 入口 | 用户得到的成果 | 发布要求 |
| --- | --- | --- |
| 首页 | 明确网站用途和可以立即开始的学习任务 | 推荐资源全部真实可用；有内容才展示入口 |
| 遗传中心 | 前置知识、学习顺序、选题入口和后续动作 | 按读者目标组织，不能只有链接卡片 |
| 概念指南 | 理解机制、区分相近概念、能自述结论 | 原创解释、明确前提、相关来源、有效图示与比较；按项目写作规范检查 |
| 原创推理案例 | 从观察到结论，并知道哪些结论不能推出 | 构造数据明确标注；推导可检查；不包装成官方真题或真实研究 |
| 解释记录工具 | 留下一份自己的推理、错误原因和下一次复习目标 | 能用、能保存/打印/下载；不夸称已经具备的功能 |
| 来源、订正与发布信息 | 理解内容依据和责任范围，能反馈错误 | 发布主体、作者与实际审核者分开；没有执行的审核不写成已完成 |

保留其他有用指南；库的广度不替代核心模块的深度。不要为每个关键词建一个页面，也不要重做全部外观当作内容整改。

## 内容取舍与审核记录

逐页填写 [处置清单](audits/content-disposition.csv)：

- 读者要完成什么任务；与最接近页面相比新增了什么。
- 科学依据的实际版本/章节；图片、案例、算式和引用是否支撑所述内容。
- 保留/修订/合并/撤下的理由；合并目标必须相关。保留内容准确的短页。
- 真实人工审阅人、版本、日期、检查范围与未解决项。没有记录则标为未证实，不暗示被专家审核。
- 技术就绪、内容就绪、人工审阅、许可及广告资格分别记录。noindex、撤下导航和阻止广告不是彼此替代品，也不是隐藏问题以便审核的方法。

新写或实质改写的教学内容：先由自动化准备来源、推导、原创性对比和预览，再供实际负责的人审阅/甄选。未确认人工内容审核时保留草稿，不能把换成更强模型当成人工审核。技术修复、只读审计、原有页面的非教学界面改善可继续按已有授权完成和发布。

## 许可与引用的边界

独立解释事实、标明核查来源、复制原文题目、改绘原图、转载 PDF 是不同用途。不能因为有引用就复制受保护的表达；也不能因为复制许可未确定就停止所有独立原创工作。对新建的来源导读按具体来源条款和实际使用方式核实；不推断“所有普通来源链接都必须先取得统一书面许可”。

NCERT、Exemplar、NTA、CBSE 不混称；官方题导读才需要匹配题号/版本/最终答案。无需把答案匹配变成纯原创记录工具的前置条件。当前 OpenStax 版本的 NC-SA 限制要单独处理，不将旧许可默认套用在现版素材上。

## 持续运行规则

1. 每天09:00读取本文件、旧路线图进度、Git状态与最新发布证据。先完成最早未完成且可行动的一项。
2. 优先解决读者能感知的问题；研究文档和计划不是网站已改善的证明。基线已经完成，不每日重做整站扫描、不反复写同一份许可说明。
3. 遇到缺少人工核查或授权：记录具体缺口，准备可审阅成果，转做不依赖该条件的原创建议、界面或工具开发；不反复通知同一障碍。
4. 变更后完成相关构建、测试、链接、移动端检查；PDF逐页渲染。只有符合当前发布门槛才按已有授权发布，并检查线上链接。
5. 没有真实数据就标注未知。获得授权的现有 GSC/GA 只用于理解需求与问题；不刷量、不假造用户反馈、不点击自己的广告，不为测试发送广告曝光。
6. 广告审核与功能发布分开。实查页面级投放资格、隐私披露和区域同意流程；不擅自修改账户、付款或购买服务，不把全局加载脚本当作已出现广告的证据。
7. 只有实质交付、失败或需要 Owner 操作时通知，分别说明本地/测试/提交/推送/部署/线上验证状态。计划完成后提交验收，不自行恢复日更。
