# Search discovery and tool use · November 26, 2026

Search Console's web-search property total for https://medqgo.com/ was 11 impressions and zero clicks for October 27 through November 24. This is a property aggregate, not a sum of query or page rows. At inspection, Google had discovered the inheritance hub but had not indexed it. The monohybrid tool was unknown to Google. Its live HTML declared noindex and pointed the canonical to the homepage.

The monohybrid cross calculator now has its own canonical URL, is eligible for indexing, appears in the XML sitemap, and has a direct link from the inheritance hub. The single-tool pilot uses the previously reviewed model and its existing presets, matrix, and record workflow.

With optional analytics consent on the production host, GA4 can measure first interaction, parent/preset changes, route inspection, successful local saves, download requests and clicks into the explanation record. The events carry no genotype values or note content. A download request measures the request only. Local and preview hosts are excluded. Browser verification intercepts analytics and advertising traffic and verifies the event queue, consent, and user workflow. It cannot confirm receipt by the GA4 property.

For the next review, inspect Google indexing for the calculator and inheritance hub, then compare property and calculator search impressions/clicks. In GA4, use users as the denominator for starts, route inspection and saves, and review returning users separately. Sparse counts are directional observations. Prioritize search discovery if there are few impressions, and usability if visitors arrive but rarely complete the core task.
