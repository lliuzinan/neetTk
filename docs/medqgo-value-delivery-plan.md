# MedQGo 学习价值整改执行计划

更新：2026-10-30，Asia/Shanghai。Owner 已要求按此方向整理整改计划。政策与发布门槛沿用 [合规路线](adsense-compliance-route.md)，发布证据记入 [进度日志](medqgo-learning-roadmap.md)，逐页结论写入 [内容处置表](audits/content-disposition.csv)。本计划替代旧按日期排列的任务队列，不表示以下功能已经交付。

## 要解决的真实问题

服务英语阅读的 NEET 生物学习者，先解决遗传学中“记住定义和比例，但说不清为什么、何时适用、错在哪里”的问题。网站的交付物是一条能走完的学习路径，以及学生自己留下的解释和复习记录。64篇指南只是待整理的内容基础，不是价值或审核通过的证据。

本轮只做遗传基础五步：分离规律 → 测交 → 不完全显性与共显性 → 两位点概率 → 连锁与重组。对应已有页面，不新开同义词页面。依据 [学习成果映射](sources/inheritance-learning-outcomes.md)，不把这五步称为整个遗传学或整个考试范围。

## 学习路径与网站结构

首页的主要入口是“开始遗传学习”，同时提供专题库和继续使用记录工具的入口；只展示已经发布的功能。

遗传中心说明适合谁、需要哪些前置概念、每一步学会什么。每步形成“提出具体困惑 → 阅读解释和有用图示 → 看推理与边界 → 写自己的解释 → 对照核查提示 → 记录仍不理解之处和复习目标”的路径。允许直接跳转与返回，不强制注册。

概念页负责一个清晰任务；推理案例负责展示推导、前提和反例；解释记录工具负责保存学生的思考。来源、订正、发布主体及实际审核范围提供可追溯依据。保留有独立用途的其他专题，暂不扩张第二个学习中心。

## 五步内容的具体成果

| 已有指南 | 学生应能做到 | 内容重点 |
| --- | --- | --- |
| `mendelian-inheritance` | 区分亲代基因型、配子与子代表型，并说明推导 | 基因传递与表达分开；期望比例不是每组后代的配额 |
| `testcross-and-unknown-genotypes` | 解释隐性测交亲本的作用与小样本局限 | 观察证据与“证明”区分；不把似然当成后验概率 |
| `incomplete-dominance-and-codominance` | 解释两种表达模式，且不混淆等位基因传递 | 不完全显性不意味着基因混合或消失 |
| `dihybrid-crosses-and-probability` | 在计算前说明何时能相乘 | 独立性、表达与存活条件；不能把熟悉比例套用所有情形 |
| `linkage-and-recombination-frequency` | 说明亲本组合、重组分子分母及结论边界 | 后代重组比例不等于发生交换的细胞比例；避免过度解释距离 |

上述是内部验收目标，不是已审核的新增教材内容。来源版本、当前适用考纲和具体表述仍须在改写时核实。

## 每次定时任务如何执行

1. 读取合规路线、本计划、最新日志与Git状态；确认上一项是否已上线，避免重复修复。
2. 选择最早未完成且未阻塞的工作包中的一个可验收成果。内容审读按主题小批次进行；不要每天重新全站扫描。
3. 开始时写清本次要解决的用户问题；结束时记录具体页面/工具、证据、剩余问题和下一步。只有计划没有成果，不算产品交付。
4. 实质教学改写准备来源、推导、相邻内容对比、预览及具体核查项，交实际负责的人审阅。此前对免疫文章的确认不自动覆盖未来教学内容。
5. 等待教学审阅时推进空白工具、布局、链接、无障碍和资料整理；已授权且符合门槛的改动测试后发布。不要重复询问相同发布许可。
6. 沿用现有每天北京时间09:00任务。现有任务已读取合规路线与日志，这两个入口指向本计划；本次不创建重复任务，不声称已修改调度器配置。

## 时间估计与重新提审

按当前代码可复用、每天有实质推进、实际审核及时的假设：第一周完成W1与记录工具可用版本；第二周完成遗传主线及PDF/HTML整合；第三至第四周完成全库处置、回归和一轮真实反馈修复。工作量与审阅等待可能延长，2–4周只是规划范围，不是承诺或Google要求。阶段完成以证据为准。

重新提审前应同时满足：公开页均有明确处置结论；已知科学错误、误导声明与重要来源缺口已解决；遗传完整路径和下载工具真实可用；实质改写已有实际审核记录；无未完成占位入口和断链；相关隐私与广告页面适用性已检查；形成真实反馈或明确尚缺的使用验证。由Owner决定并操作提审，不自动提交，不保证通过。

真实反馈用于验证产品价值，不是虚构访问量要求。若仍无实际使用证据，应诚实报告并继续验证，不能凭文章数或工具数量宣布问题解决。
