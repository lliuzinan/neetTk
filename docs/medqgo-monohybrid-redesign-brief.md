# MedQGo 单基因杂交推演器改版任务书

## 给设计模型的指令

请以学习产品设计师的身份，重设计 MedQGo 的 Monohybrid Cross Explorer。先体验 `http://localhost:3131/neet-ug/biology/tools/monohybrid-cross`。如本地预览未运行，从仓库的 `app/neet-ug/biology/tools/monohybrid-cross/page.tsx`、`components/MonohybridExplorer.tsx` 和 `components/MonohybridExplorer.module.css` 了解现状。交付一套可定稿、可逐项验收的设计规格和预览，供另一模型按稿实现。这一轮交付设计，不修改现有产品代码。

读者是用英文复习生物的 NEET-UG 学生。一次典型操作是打开页面，选择已知亲本，找到任一后代组合的概率来源，再说明为什么同一基因型可能由两条路径得到。另一个操作是改变一方亲本，对照哪些组合消失，并把推理追加进原有学习记录。设计须让这两条路径都能顺畅完成。

现有页面使用大标题区、前置说明、重复卡片和装饰性编号。亲本、配子、方格与结果分布在多个大区块里，页面上下滚动时难以对照。页面标题也没有直接说明工具名称。新版把重点放在同一个计算工作区的观察与比较上。

## 设计任务表

| 顺序 | 设计任务 | 必交产物 | 验收标准 |
| --- | --- | --- | --- |
| 1 | 确定页面结构 | 一个定稿方向，标出标题、亲本、矩阵、推导、汇总、记录入口与来源 | 桌面 1440×900 下，标题、亲本、矩阵和关键结果可一起查看。移动端 390px 下，首屏可修改亲本并看到矩阵起始位置 |
| 2 | 设计核心交互 | 1440px 和 390px 高保真稿及可操作原型。标清行列与对应亲本、当前选中单元格、组合概率及逐格推导的位置 | 选格后能一眼对照对应的行列和乘法，聚合结果能区分同一基因型的两条路径。切换亲本时，所有显示同步更新 |
| 3 | 补齐关键状态 | 默认 `Aa × Aa`、`Aa × aa`、`AA × aa`、四格中另一格被选中、键盘焦点、保存成功、保存失败、关闭 JavaScript 的示例状态 | 至少画出 2×2、非对称 2×1 或 1×2、1×1。状态含义由文字或边框等共同表达。说明改亲本后默认选中哪一格及焦点如何保留 |
| 4 | 定稿视觉和文案 | 标注版布局、最终英文文案、组件状态及设计变量 | 给出内容宽度、断点、列宽、间距、字号、行高、颜色、边框和焦点样式。使用表格数字对齐。正文与控件对比度达到 WCAG AA，触控目标以 44px 为设计目标 |
| 5 | 写实现交接 | 按页面区块逐项标注现有代码位置、数据来源、改动顺序与验收用例 | 执行模型能按稿实现所有关键状态。设计稿、示例数值与文案一致，每个交互有明确触发方式与结果 |

建议从紧凑的工作台着手。桌面可以把杂交方格及选格推导放在相邻区域，移动端按亲本 → 方格 → 当前选格推导 → 概率汇总排列。优先通过对齐、数字与清晰标注建立层级，沿用 MedQGo 品牌色。最终交付一个定稿方向，说明为何该结构便于跨区对照。来源、详尽假设和记录操作的位置要在图上标明，主要模型条件仍应在表型结果旁可见。

## 数据与行为契约

- 继续使用 `lib/monohybrid.ts` 计算和 `lib/explanationRecords.ts` 的既有记录格式。覆盖 `AA`、`Aa`、`aa` 的九种有序亲本组合。矩阵的行列与亲本标签一致，合并重复配子类型后每轴为一项或两项。
- 汇总分为基因型与完全显性条件下的表型。单元格展示一条组合路径，基因型汇总加总所有对应路径。概率表示每个后代在给定模型下的结果。
- `Aa × Aa` 为 `25% AA / 50% Aa / 25% aa`，表型为 `75% / 25%`。两个 `Aa` 单元格各为 `25%`。`Aa × aa` 为 `0% AA / 50% Aa / 50% aa`。`AA × aa` 为 `100% Aa`，表型为 `100% / 0%`。
- 保存只在用户明确触发时追加到 `segregation` 的推理字段，保留原笔记、其他字段及主题。保留文本下载与返回学习记录入口。保存失败时可下载，刷新和返回记录后的内容需验证。
- 范围是单个常染色体位点、两种等位基因的教学模型。真实家庭风险不在产品范围内。虚构家系分析仍是独立后续工作包。

## 给执行模型的指令

先阅读定稿预览、标注与状态表，再按标注实现杂交推演器及其遗传学习中心入口。以现有计算模块与记录行为为基线。需要设计决定的缺口列出来交回设计方。实现后运行 `npm test`，用真实浏览器核对 320 / 390 / 768 / 1440px，交付对照截图与检查结果。除默认桌面和移动版，核对非对称方格、选中和焦点、保存成功和失败，以及关闭 JS 时默认推导可读。检查 320px 无横向溢出、键盘可切换亲本与选择单元格、旧笔记保存后仍在、导出和返回链接可用。

涉及新教学表述或推导变更，沿用项目的实际人工内容核验要求。此任务的实现交付是本地可验收版本，发布状态单独记录。
